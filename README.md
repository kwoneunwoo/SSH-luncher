SSH-launcher
---

### 💡 아이디어
여러 SSH 서버에 쉽게 접속할 수 있도록 도와주는 런처 개발.


### 🚀 사용 방법
1. [`servers.json.example`](/servers.json.example) 파일의 내용을 참고하여 `servers.json` 파일 제작.
2. [`main.exe`](/main.exe)를 `servers.json`과 같은 폴더에 위치한 후 실행.


### 🧑‍💻 개발자 실사용 환경
현재 저는 코파일럿키를 단축키로 매핑하여 사용 중입니다.

- OS: `Windows 11`
- 키 매핑 프로그램: [`PowerToys`](https://apps.microsoft.com/detail/xp89dcgq3k6vld)의 `Keyboard Manager`


### ⚙️ 기술 스택
- Golang
